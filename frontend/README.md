# Frontend — ClinicFlow

Angular 19 + Tailwind v4. Ver [CLAUDE.md](CLAUDE.md) para arquitectura y convenciones, y el README de la raíz para levantar el stack.

```bash
pnpm start          # http://localhost:4200 (proxy /api -> :8080)
pnpm build
pnpm format         # Prettier
pnpm test           # Karma
pnpm e2e:smoke      # requiere el stack levantado
```
